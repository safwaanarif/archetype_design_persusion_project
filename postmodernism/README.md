# Postmodernist Design

**Owner:** Konrad Sikorski

Postmodern design emerged in the 1960s through the 1980s as a reaction against modernism. Where modernism valued simplicity, function, and "less is more," postmodern design brought back ornament, color, humor, historical references, and irony. These pages cover six postmodern styles: what each one is, where it came from, how it challenges modernist ideas, and how to use it in design and branding today.
